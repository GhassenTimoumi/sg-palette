# SG Palette — Site vitrine

Site web moderne et bilingue (Français / العربية) pour **SG Palette (SGP)**, le leader de la
fabrication et commercialisation de palettes en bois en Tunisie.

## ✨ Fonctionnalités

- **Bilingue FR / AR** avec support RTL complet (langue par défaut : français)
- **Illustrations de palettes générées en SVG** (galerie + hero), au style isométrique du logo
- **Animation d'entrée** « assemblage des planches » (preloader + hero)
- **Calculateur de devis en ligne** (type, format, état, traitement export, quantité → prix estimé en DT)
- **Galerie produits** (palettes standard, EUR/EPAL, caisses, renforcées, sur-mesure, empilées)
- **Boutons réseaux sociaux** (WhatsApp, Facebook, Instagram, LinkedIn) + **Google Maps**
- Design responsive, animations au défilement, compteurs animés, SEO + données structurées

## 🗂 Structure

```
index.html          Page unique multi-sections
css/styles.css      Design system de la marque + RTL
js/pallets.js       Générateur d'illustrations de palettes (SVG isométrique)
js/i18n.js          Dictionnaire FR/AR + bascule de langue
js/script.js        Interactions (nav, galerie, calculateur, social, entrée)
assets/             Logo + favicon
```

## 🚀 Lancer en local

```bash
python3 -m http.server 8080
# puis ouvrir http://localhost:8080
```
